## ✦ What Is Botagram?

**Botagram** is a full-stack SaaS platform that lets you **automate your presence across 11+ social networks** through a unified dashboard. Whether you need Instagram DM workflows, YouTube upload pipelines, LinkedIn lead generation, or TikTok scheduling — Botagram provides ready-to-use bots with a premium 3D interactive experience.

| | | |
|---|---|---|
| 🎯 **Multi-platform** | 💳 **5 payment methods** | 🎨 **3D Interactive UI** |
| 11 social networks automated | Stripe · PayPal · Cryptomus · Wise · Dodo | Spline robot head follows cursor |
| 📱 **Responsive** | 🔐 **GDPR Compliant** | ⚡ **Performance optimised** |
| Mobile-first design | Cookie consent · Privacy · Refund policies | Device detection · Lazy Spline · Reduced motion |

## ✦ Quick Start

### Prerequisites

```bash
node >= 18
npm  >= 9
```

### Clone & Install

```bash
git clone https://github.com/vakandi/Botagram.git
cd Botagram
npm install
```

### Run Development Server

```bash
npm run dev
```

Open **[http://localhost:5173](http://localhost:5173)** — HMR enabled.

### Build for Production

```bash
npm run build
npm run preview  # Preview production build locally
```

## ✦ API Reference

### Guest Checkout (FastAPI Backend)

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/guest/quote` | `POST` | Get price quote for a bot service |
| `/api/guest/checkout` | `POST` | Create payment link & order |
| `/api/guest/status/:token` | `GET` | Check payment status |

**Quote Request Example:**
```bash
curl -X POST "https://paiement.botagram.fr/api/guest/quote" \
  -H "Content-Type: application/json" \
  -d '{
    "order_type": "single",
    "currency": "EUR",
    "single": {
      "service_id": "Instagram",
      "quantity": 1,
      "target_url": "https://botagram.fr/bots/instagram",
      "comments": "Instagram automation bot"
    }
  }'
```

**Quote Response:**
```json
{
  "amount": 29.99,
  "currency": "EUR",
  "items": [{
    "label": "Instagram Bot - Automatisation",
    "quantity": 1,
    "unit_price": 29.99,
    "total": 29.99
  }],
  "order_type": "single"
}
```
